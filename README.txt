SHORTEST ROUTE PLANNER USING DIJKSTRA'S ALGORITHM (Java)

Requirements: JDK 11 or newer

Compile (once):   mkdir out
                  javac -d out src/*.java      (on Windows: src\*.java)

Run GUI:          java -cp out RouteGui
Run console menu: java -cp out Main

Console menu option 6 runs the test cases. Option 7 runs the benchmark and writes benchmark_results.csv.
Benchmark times will differ on your machine. Re-run it and update the report with your own numbers.
